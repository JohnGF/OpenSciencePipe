\begin{abstract}
Traditional bibliometric science mapping workflows frequently rely on desktop applications (such as VOSviewer, CiteSpace, and Bibliometrix) that require manual data export from commercial databases, depend on keyword co-occurrence heuristics that discard semantic context, and struggle to scale computationally on large citation graphs. We introduce \textbf{OpenSciencePipe}, an open-source computational framework for autonomous bibliometric discovery and science mapping. OpenSciencePipe integrates multi-source API harvesting (OpenAlex, Crossref, Semantic Scholar, PubMed), programmatic Levenshtein deduplication, GPU-accelerated graph analytics via RAPIDS \texttt{cugraph}, density-based neural topic modeling (BERTopic with HDBSCAN), and automated publication-grade \LaTeX\ compilation. Across an empirical benchmark suite of published scientometric corpora, GPU acceleration executes Louvain community detection and PageRank on co-authorship graphs of over 118,000 nodes and 569,000 edges in 0.84 seconds on consumer hardware (NVIDIA GeForce RTX 2060, 6\,GB VRAM), achieving a $2{,}000\times$ speedup over single-threaded CPU NetworkX baselines (28.0 minutes). Head-to-head thematic comparisons against classical Latent Dirichlet Allocation (LDA) demonstrate that while Dirichlet mixture assignment forces 100\% document allocation ($0.0\%$ outliers) and yields vocabulary redundancy ($\text{TD} = 0.40\text{--}0.74$), density-based clustering isolates unclustered boundary literature into an explicit noise pool (Topic~$-1$), delivering high topic diversity ($\text{TD} = 0.69\text{--}1.00$). Furthermore, the pipeline exhibits strong macro-structural concordance with established geopolitical hierarchies, replicating top-publishing nations with up to $100.0\%$ overlap and Spearman rank correlation $\rho \ge 0.96$ ($p < 0.001$). By automating the entire trajectory from API query execution to reproducible \LaTeX\ compilation, OpenSciencePipe establishes an open, scalable foundation for next-generation informetric research.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Rigorous research synthesis requires operating across two complementary levels of analysis: macro-level exploratory science mapping and micro-level confirmatory evidence synthesis \cite{cobo2011science, page2021prisma}. First, exploratory mapping uncovers the intellectual, thematic, and collaborative topologies of an entire discipline through co-authorship networks, citation backbones, and co-word landscapes \cite{van2010software, chen2006citespace, aria2017bibliometrix}. Second, confirmatory evidence synthesis aggregates empirical effect sizes across primary studies adhering to systematic review protocols (such as PRISMA \cite{page2021prisma}), requiring structured literature screening, risk-of-bias evaluation, and inverse-variance statistical pooling \cite{revman2020, viechtbauer2010conducting}.

Despite their shared reliance on bibliographic corpora, these two traditions remain largely unintegrated, and four bottlenecks follow. Data ingestion depends on manual flat-file exports from commercial databases \cite{moral2020software}, with per-batch download caps that complicate provenance. Bag-of-words thematic models ignore semantic context and force every document into a topic \cite{blei2003latent, campello2013density, grootendorst2022bertopic}. Graph analysis of large citation corpora strains commodity CPU hardware, which discourages exploratory iteration. Finally, title and abstract screening consumes hundreds of reviewer hours for a small fraction of eligible records \cite{cohen2006reducing, van2021active}, and screening false negatives can bias pooled effect estimates. The tool-specific limitations behind these bottlenecks are catalogued in Section~\ref{sec:related_work}.

Concurrently, the scientific information landscape is shifting toward open bibliographic indices, most notably OpenAlex \cite{priem2022openalex}, Crossref \cite{hendricks2020crossref}, and Semantic Scholar \cite{kinney2023semantic}, which provide programmatic access to hundreds of millions of interconnected scholarly records with structured metadata. In parallel, local open-weight Large Language Models (LLMs) deployed on optimized inference runtimes (e.g., via Ollama) facilitate reproducible, zero-shot document triage without cloud API expenses or proprietary data exposure.

Building upon this open infrastructure, we introduce \textbf{OpenSciencePipe}, an integrated, open-source computational framework that unifies macro-level exploratory science mapping and micro-level PRISMA meta-analysis within a single, autonomous, reproducible workflow. Rather than requiring researchers to manually shuttle flat files between fragmented, single-purpose software packages, OpenSciencePipe provides an end-to-end pipeline that ingests scholarly records from open APIs, constructs GPU-accelerated graph topologies, executes density-based neural topic modeling, conducts structured zero-shot screening, pools empirical effect sizes, and compiles publication-ready \LaTeX{} manuscripts across standard journal templates.

We benchmark OpenSciencePipe against 26 published bibliometric studies originally conducted across 11 software ecosystems, alongside four canonical meta-analyses in clinical medicine, epidemiology, and econometrics (30 empirical evaluations in total). The evaluation covers five dimensions: computational scalability, thematic quality and noise isolation, geopolitical rank concordance, screening fidelity and labor reduction, and meta-analytic replication fidelity. Section~\ref{sec:benchmark_design} defines the metrics, and Section~\ref{sec:results} reports the results.

Whereas existing science mapping environments require manual parameter calibration across multi-stage graphical user interfaces (such as threshold selection, time-slice partitioning, and layout tuning in CiteSpace or SciMAT), OpenSciencePipe operates via a declarative, single-query specification. This design abstracts multi-tier data ingestion, topological discovery, and evidence synthesis into an automated, fully reproducible execution run.

\section{Related Work}
\label{sec:related_work}

\subsection{Foundations of Science Mapping and Informetrics}
Quantitative science mapping emerged to uncover macro-level knowledge structures within scientific specialties. Methodological foundations originate in bibliographic coupling \cite{kessler1963bibliographic} and co-citation analysis \cite{small1973co}, where Small and Griffith \cite{small1974structure} established that citation graph topologies reflect the intellectual and social consensus of a discipline. In parallel, co-word analysis was formulated by Callon et al. \cite{callon1983co} to map conceptual dynamics through lexical co-occurrences. Later, Cobo et al. \cite{cobo2011science, cobo2012scimat} formalized these distinct relational modalities (citation, co-citation, and co-word networks) into a unified scientometric workflow spanning retrieval, preprocessing, network extraction, normalization, spatial layout, and cluster analysis.

\subsection{Contemporary Informetric Ecosystems and Operational Limits}
Over the past three decades, the informetrics community has developed specialized tools targeting distinct sub-problems of literature analysis. These tools can be organized into five operational classes:

\paragraph{Exploratory Science Mappers} Contemporary bibliometric mapping is primarily anchored by three desktop suites: \textbf{VOSviewer} \cite{van2010software}, which optimizes the Visualization of Similarities (VOS) layout normalized by association strength to map co-authorship and co-occurrence; \textbf{CiteSpace} \cite{chen2006citespace}, which detects progressive scientific frontiers and pivotal transition nodes using Kleinberg's burst detection \cite{kleinberg2003bursty} across time-sliced networks; and \textbf{Bibliometrix} (\texttt{biblioshiny}) \cite{aria2017bibliometrix}, an extensive R package evaluating classical empirical laws (Lotka, Bradford, Zipf) and strategic Callon thematic diagrams. Despite their visual clarity, these tools operate as isolated GUI desktop applications constrained by workstation CPU memory and manual batch exports.

\paragraph{Longitudinal Thematic Evolution Engines} Dedicated platforms like \textbf{SciMAT} \cite{cobo2012scimat} and the \textbf{Sci2 Tool} \cite{borner2010science} model longitudinal science mapping by dividing bibliographic data into sequential time intervals, evaluating Callon centrality versus density to track how thematic clusters merge, split, or perish across eras. However, they require manual configuration between stages.

\paragraph{Direct Citation Genealogies and Historiographs} Tools such as \textbf{CitNetExplorer} \cite{van2014citnetexplorer} and \textbf{HistCite} \cite{garfield2004histcite} render directed chronological citation networks to trace direct parent-to-descendant intellectual lineages (Garfield historiographs). Modern web services (e.g., Connected Papers, Litmaps) provide seed-paper neighborhood expansion. Nevertheless, these platforms remain tied to proprietary Web of Science flat-file formats or single-seed queries rather than end-to-end corpus synthesis.

\paragraph{Large-Scale Graph and Community Engines} General complex network engines like \textbf{Gephi} \cite{bastian2009gephi} and \textbf{Pajek} \cite{batagelj1998pajek} provide ForceAtlas2 layouts and Louvain/Leiden modularity for large graphs. While powerful, they are domain-agnostic, require complex intermediate graph conversions (\texttt{.gexf}, \texttt{.net}), and exhibit severe memory bottlenecks and UI latency when handling dense co-citation graphs exceeding $10^5$ edges on commodity hardware.

\paragraph{Scripted Extraction Utilities and API Wrappers} Programmatic utilities including \textbf{Bibexcel} \cite{persson2009bibexcel}, \textbf{metaknowledge} \cite{mclevey2017metaknowledge}, and \textbf{pybliometrics} \cite{rose2019pybliometrics} automate bibliographic matrix extraction or wrap proprietary APIs (such as Elsevier Scopus). However, they function strictly as extraction aids, requiring researchers to write  glue code or manually connect extraction with downstream statistical modeling or visualization.

\subsection{Evidence Synthesis, Active Screening, and Meta-Analysis Tools}
In empirical evidence synthesis, the PRISMA 2020 guidelines \cite{page2021prisma} specify protocols for systematic identification, screening, eligibility auditing, and study inclusion. While active-learning platforms like \textbf{ASReview} \cite{van2021active} and \textbf{Rayyan} \cite{ouzzani2016rayyan} have accelerated title and abstract triage through machine-assisted prioritization, they remain isolated screening silos dependent on manual CSV/RIS imports. For quantitative synthesis, statistical packages such as Cochrane \textbf{RevMan} \cite{revman2020} and R \textbf{\texttt{metafor}} \cite{viechtbauer2010conducting} provide inverse-variance and random-effects models (e.g., DerSimonian--Laird \cite{dersimonian1986meta}, REML), but remain entirely disconnected from the upstream search, harvesting, and deduplication phases of the research lifecycle.

\subsection{Deep Learning, Dense Embeddings, and Density-Based Noise Isolation}
Recent advances in natural language processing (NLP) address long-standing limitations in lexical bibliometrics. Classical frequency-based approaches, including co-word matrices and Latent Dirichlet Allocation (LDA) \cite{blei2003latent}, rely on bag-of-words assumptions that ignore syntactic context, polysemy, and vocabulary mismatch. Pretrained transformer architectures project text into dense continuous vector spaces encoding semantic context (BERT \cite{devlin2018bert}, Sentence-BERT \cite{reimers2019sentence}). 

Building upon these representations, BERTopic \cite{grootendorst2022bertopic} coordinates three complementary stages: (i) encoding title and abstract corpora into dense contextual vectors, (ii) reducing dimensionality via UMAP \cite{mcinnes2018umap}, and (iii) grouping semantically coherent documents into clusters using HDBSCAN \cite{campello2013density}. Crucially, HDBSCAN isolates peripheral or multidisciplinary literature into an explicit noise pool (Topic~$-1$). Integrating dense contextual representations with density-based clustering provides a principled alternative to bag-of-words methods, capturing cohesive thematic clusters without forcing peripheral literature into artificial groupings.

\subsection{Methodological and Architectural Capabilities Integrated in OpenSciencePipe}
Beyond addressing the operational silos of legacy tools, OpenSciencePipe integrates six cohesive methodological capabilities into a single reproducible engine. Their empirical performance is quantified in Section~\ref{sec:results}; here we describe how each capability is architected:

\begin{enumerate}
    \item \textbf{Unified Ingestion and Reproducible Execution Pipeline:} While existing tools require fragmented script wrappers or manual GUI exports across disparate file formats, OpenSciencePipe establishes an end-to-end declarative framework executing federated API harvesting across open scholarly indices (OpenAlex, Crossref, Semantic Scholar, PubMed), token-sorted Levenshtein deduplication, and automated reporting from a single query specification.
    \item \textbf{GPU-Resident Graph Analytics:} Citation and co-authorship graphs are stored in a Compressed Sparse Row (CSR) layout in device memory using NVIDIA RAPIDS \texttt{cugraph} and \texttt{cudf}. Adjacency traversal for Louvain community detection and PageRank executes via contiguous memory access and massively parallel edge relaxation rather than single-threaded CPU graph traversals, with zero host-device transfer penalties between algorithms.
    \item \textbf{Density-Based Noise Rejection in Thematic Modeling:} Dense sentence embeddings are reduced with UMAP and clustered via HDBSCAN, defining clusters as regions of high local density separated by sparse boundaries. Documents lying outside dense manifolds are assigned to an explicit noise pool (Topic~$-1$) rather than forced into artificial topics as required by traditional centroid or Dirichlet models, preserving distinct topic centroids and high vocabulary diversity.
    \item \textbf{Schema-Constrained Local Screening with Auditability:} Candidate records can be evaluated by a local open-weight LLM governed by greedy decoding ($T = 0.0$) and constrained to a structured JSON schema. By enforcing deterministic schema compliance and logging explicit inclusion rationales, the engine avoids commercial API dependencies, prevents data leakage, and generates a reproducible audit trail for triage decisions.
    \item \textbf{Downstream Evidence Synthesis Interfaces:} The framework provides modular interfaces bridging bibliometric discovery with downstream systematic review screening and meta-analytic pooling, establishing an extensible bridge evaluated in companion work.
    \item \textbf{Automated Reproducible Report Scaffolding:} Figures, formatted \LaTeX{} tables, and bibliography keys are emitted directly by analysis modules and assembled into camera-ready manuscript templates, ensuring complete synchronization between source data, analysis code, and published figures.
\end{enumerate}

\subsection{Tier 1: Multi-Source API Ingestion and Canonical Schema}
Coordinated by the \texttt{DataOrchestrator} module, OpenSciencePipe interfaces asynchronously with open scholarly REST endpoints, including OpenAlex \cite{priem2022openalex}, Crossref \cite{hendricks2020crossref}, Semantic Scholar \cite{kinney2023semantic}, and PubMed \cite{sayers2022database}, alongside authenticated developer endpoints such as Elsevier Scopus and IEEE Xplore. Retrieved records are validated and mapped into a strongly typed canonical publication model:
\begin{equation}
\mathcal{P}_i = \langle \text{Title}_i, \text{Abstract}_i, \text{Authors}_i, \text{Year}_i, \text{Affiliations}_i, \text{DOI}_i, \text{Citations}_i \rangle
\end{equation}
This ingestion layer abstracts disparate vendor schemas into a uniform internal representation, ensuring consistent downstream processing regardless of data provenance.

\subsection{Tier 2: Two-Stage Record Deduplication}
Multi-source querying inherently introduces duplicate and near-duplicate records with heterogeneous metadata. OpenSciencePipe resolves duplicates via a two-stage deduplication protocol. First, primary matching performs exact identifier normalization by resolving Digital Object Identifiers (DOIs), stripping URI prefixes (e.g., \texttt{https://doi.org/}), removing extraneous whitespace, and standardizing casing. Second, for records lacking DOIs or containing typographical noise, the pipeline evaluates title similarity via token-sorted Levenshtein distance. Titles are lowercased, stripped of non-alphanumeric punctuation, and split into word tokens that are sorted lexicographically before string reconstruction. The edit distance between normalized strings $T'_a$ and $T'_b$ is measured via the Levenshtein metric \cite{levenshtein1966binary}:
\begin{equation}
\text{Sim}(T'_a, T'_b) = 1 - \frac{\text{Lev}(T'_a, T'_b)}{\max(|T'_a|, |T'_b|)}
\end{equation}
where $|T'|$ denotes string character length. Candidate record pairs satisfying $\text{Sim}(T'_a, T'_b) \ge 0.92$ are merged, consolidating citation counts and resolving author affiliations into the most complete canonical entry.

\subsection{Tier 3: GPU-Accelerated Network Topologies via cuGraph}
\label{sec:tier3}
Network extraction and topological analysis scale natively to large bibliometric corpora using NVIDIA RAPIDS (\texttt{cudf} and \texttt{cugraph}). By utilizing memory-conscious chunking and Compressed Sparse Row (CSR) representations, the framework processes graphs with tens of thousands of publications on standard consumer GPUs.

For an author set $\mathcal{A}$ and publication set $\mathcal{D}$, the co-authorship adjacency matrix $\mathbf{A} \in \mathbb{R}^{|\mathcal{A}| \times |\mathcal{A}|}$ encodes the frequency of co-authored publications $A_{uv}$ between authors $u$ and $v$. Sub-field communities are extracted natively on GPU memory by maximizing Newman-Girvan modularity $Q$ via the Louvain algorithm \cite{blondel2008fast}:
\begin{equation}
Q = \frac{1}{2m} \sum_{i,j} \left[ A_{ij} - \frac{k_i k_j}{2m} \right] \delta(c_i, c_j)
\end{equation}
where $k_i = \sum_j A_{ij}$ is the degree of node $i$, $m = \frac{1}{2}\sum_{ij} A_{ij}$ denotes total edge weight, and $\delta(c_i, c_j) = 1$ when vertices $i$ and $j$ share community assignment $c$.

Simultaneously, vertex prestige across citation and collaboration graphs is computed via GPU-accelerated PageRank \cite{page1999pagerank}:
\begin{equation}
\mathbf{p} = \left(\frac{1-d}{N}\right) \mathbf{1} + d \mathbf{M} \mathbf{p}
\end{equation}
where $\mathbf{M}$ is the column-stochastic transition matrix, $d = 0.85$ is the damping factor, $N$ is vertex cardinality, and $\mathbf{p}$ is normalized such that $\mathbf{1}^\top \mathbf{p} = 1$. In parallel, co-citation ($\mathbf{X}^\top \mathbf{X}$) and bibliographic coupling ($\mathbf{X}\mathbf{X}^\top$) graphs are constructed via sparse matrix multiplication, avoiding quadratic pairwise iteration.

To prevent artificial inflation or fragmentation of vertex degrees in co-authorship graphs, author entities are disambiguated prior to network construction. The pipeline links persistent identifiers (such as ORCID and OpenAlex author IDs) where available. For records lacking persistent identifiers, disambiguation is achieved through a multi-attribute similarity function combining normalized author surname with first-name initial, publication co-authorship context, institutional affiliation signatures, and temporal overlap. Ambiguous instances that fail to satisfy confidence thresholds are partitioned conservatively to prevent over-representing authors who share common surnames.

\subsection{Tier 4A: Unsupervised Neural Thematic Discovery and Noise Rejection}
To capture thematic structure beyond frequency-based bag-of-words representations, the NLP engine within OpenSciencePipe implements a three-stage neural topic discovery pipeline. First, title and abstract corpora are projected into a continuous dense semantic space $\mathbf{e}_i \in \mathbb{R}^{384}$ using the \texttt{all-MiniLM-L6-v2} sentence transformer \cite{reimers2019sentence}. Second, UMAP \cite{mcinnes2018umap} performs non-linear manifold dimensionality reduction down to $\mathbb{R}^{5}$, preserving both local metric neighborhoods and global continuum geometry while reducing dimensionality for density estimation. Third, HDBSCAN \cite{campello2013density} identifies clusters based on continuous density distributions rather than geometric centroid proximity.

A key feature of this architecture is explicit noise isolation. Unlike hard-partitioning algorithms (such as $k$-means or standard LDA) that force every document into a topic cluster, HDBSCAN classifies publications residing in sparse boundary regions as noise ($\text{Topic} = -1$). Isolating peripheral or multidisciplinary literature prevents boundary contamination of substantive domain clusters.

\subsection{Modular Downstream Interfaces: Systematic Screening and Meta-Analysis}
Beyond unsupervised exploratory science mapping, OpenSciencePipe integrates modular downstream interfaces bridging macroscopic bibliometric discovery with microscopic systematic evidence synthesis. Managed by the \texttt{SystematicOrchestrator} module, candidate literature records can be screened via deterministic regular-expression filtering (\texttt{GrepRelevanceFilter}), continuous semantic embedding similarity (\texttt{EmbeddingRelevanceFilter}), or local zero-shot inference with open-weight models via Ollama under structured JSON schema constraints. For quantitative synthesis, the companion \texttt{MetaOrchestrator} provides statistical pooling interfaces implementing the DerSimonian--Laird random-effects model \cite{dersimonian1986meta}, generating forest plots and funnel plots within the execution environment. Because systematic review screening and clinical effect-size extraction follow distinct confirmatory methodologies, their dedicated empirical benchmark evaluation is detailed in companion work \cite{page2021prisma}.

\subsection{Tier 5: Automated Scientific Compilation and Manuscript Generation}
To ensure end-to-end reproducibility and eliminate manual transcription errors, the central pipeline manager coordinates \texttt{LatexExporter} and visualization services to synthesize all analytical outputs into publication-ready formats. 

The compilation engine generates a complete manuscript (\nolinkurl{paper_scaffold.pdf}). It maps and typesets up to 25 publication-grade vector figures, synchronizes computed statistical metrics into validated \LaTeX\ tabular environments, formats structured PRISMA 2020 summaries, and resolves cross-references autonomously. A companion local interface (\texttt{run\_local.py}) is provided for interactive inspection.

\subsubsection{Specialized Informetric and Synthesis Visual Taxonomy}
Beyond standard co-authorship graphs and forest plots, the visualization engine produces a suite of domain-diagnostic figures. Evidence Gap Maps (EGMs) present 2D bubble matrices cross-tabulating intervention modalities against clinical or technological outcomes to reveal unexplored research voids under the Campbell/3ie framework. Longitudinal dynamics are captured through Thematic Evolution Sankey Diagrams, which trace how thematic clusters divide, merge, or decay across chronological epochs, and Kleinberg Burst Timelines, which employ 2-state automatons to detect accelerations in citation momentum and emergent terminology bursts \cite{kleinberg2003bursty}. Algorithmic transferability is mapped via Method-Application Matrices that bicluster computational techniques against practical target domains. Finally, Percolation Phase Transition Diagnostics quantify giant connected component emergence via the Molloy--Reed criterion, detecting the tipping point where fragmented subfields transition into an integrated scientific discipline.

\subsection{Quantitative Evaluation Metrics}
We formalize a multi-tier evaluation framework spanning macro-structural concordance, neural topic quality, zero-shot screening accuracy, and meta-analytic synthesis agreement:

\subsubsection{Top-\texorpdfstring{$K$}{K} Geopolitical Hierarchy Concordance}
Following cross-database scientometric validation protocols \cite{visser2021large, martin2021google}, we assess whether OpenSciencePipe replicates published national collaboration networks extracted from author country attributions. For nation set $\mathcal{E}$ at benchmark depth $K$, topological overlap is measured by:
\begin{equation}
\text{Overlap}_K(\mathcal{E}) = \frac{|\mathcal{R}_{\text{pipeline}}^{(K)}(\mathcal{E}) \cap \mathcal{R}_{\text{benchmark}}^{(K)}(\mathcal{E})|}{|\mathcal{R}_{\text{benchmark}}^{(K)}(\mathcal{E})|} \times 100\%
\end{equation}
Ordinal rank fidelity across conjointly identified entities is evaluated via the two-tailed Spearman rank-order correlation coefficient:
\begin{equation}
\rho = 1 - \frac{6 \sum_{i=1}^n d_i^2}{n(n^2 - 1)}, \quad t = \rho \sqrt{\frac{n-2}{1-\rho^2}} \sim t_{n-2}
\end{equation}
where $d_i$ is the rank deviation between the pipeline-derived frequency rank and the published ground truth rank for entity $i$. To evaluate top-$K$ lists with non-conjoint or truncated elements without restricting comparisons solely to conjoint intersections, rank agreement is complemented by Rank-Biased Overlap (RBO) \cite{webber2010similarity}.

\subsubsection{Topic Diversity (\texorpdfstring{$\text{TD}$}{TD})}
Following topic modeling evaluation standards in continuous embedding spaces \cite{dieng2020topic}, topic diversity ($\text{TD}$) measures the lexical uniqueness across discovered themes. For $K$ topics, each represented by its top-$M$ vocabulary terms ($M=10$), topic diversity is quantified by the proportion of unique words across all topic lists:
\begin{equation}
\text{TD} = \frac{|\bigcup_{k=1}^K \mathcal{W}_k^{(M)}|}{K \times M} \in [0, 1]
\end{equation}
where $\text{TD} = 1.0$ indicates completely distinct topic vocabularies with zero term overlap, and lower values denote mutual lexical redundancy across discovered clusters.

\subsubsection{Topic Coherence via Normalized Pointwise Mutual Information (\texorpdfstring{$C_{\text{NPMI}}$}{C\_NPMI})}
Semantic coherence of each discovered topic is evaluated through corpus-level co-occurrence of top terms using Normalized Pointwise Mutual Information ($C_{\text{NPMI}}$) \cite{bouma2009normalized, roder2015exploring}. While NPMI serves as a standard automated baseline for lexical interpretability, its correlation with human semantic ratings varies across dense neural representations \cite{hoyle2021automated}:
\begin{equation}
\label{eq:npmi}
C_{\text{NPMI}}(\mathcal{W}_k) = \frac{2}{M(M-1)} \sum_{i=1}^{M-1} \sum_{j=i+1}^M \frac{\log \frac{P(w_i, w_j) + \epsilon}{P(w_i)P(w_j)}}{-\log(P(w_i, w_j) + \epsilon)}
\end{equation}

\subsubsection{Graph Community Modularity (\texorpdfstring{$Q$}{Q}) and Computational Latency}
To evaluate graph community partitioning fidelity and computational scalability, we evaluate Newman's modularity metric $Q$ \cite{blondel2008fast, traag2019louvain} across co-authorship networks:
\begin{equation}
Q = \frac{1}{2m} \sum_{ij} \left( A_{ij} - \frac{k_i k_j}{2m} \right) \delta(c_i, c_j)
\end{equation}
where $A_{ij}$ represents the collaborative edge weight between author nodes $i$ and $j$, $k_i = \sum_j A_{ij}$ is the nodal degree, $m = \frac{1}{2}\sum_{ij} A_{ij}$ denotes total network edge weight, and $\delta(c_i, c_j)$ indicates community membership. Scalability is evaluated via wall-clock speedup $S = t_{\text{CPU}} / t_{\text{GPU}}$, benchmarking single-threaded NetworkX execution against device-resident GPU cuGraph execution under identical graph structures.

\section{Empirical Results and Comparative Findings}
\label{sec:results}

\subsection{Thematic Diversity, Semantic Coherence, and Noise Rejection}
Table~\ref{tab:validation_thematic_clustering} summarizes thematic clustering performance and geopolitical topological alignment across the benchmark suite.

\input{tables/tab_validation_thematic_clustering.tex}

Three primary methodological patterns emerge from the empirical clustering results. First, the framework demonstrates high thematic diversity across disciplines: in corpora exhibiting active topic structures, the mean topic diversity was $\overline{\text{TD}} = 0.80$ (median $0.80$, ranging from $0.62$ to $0.95$ across 20 active corpora). This demonstrates that contextual Sentence-BERT embeddings coupled with UMAP manifold reduction prevent topic collapse into redundant vocabulary sets. 

Second, the HDBSCAN Topic~$-1$ density-based noise rejection mechanism isolated an average of $32.1\%$ of documents as unclustered boundary literature across active corpora (ranging from $0.0\%$ in highly concentrated domains to $56.5\%$ in heterogeneous multi-period domains such as Distance Learning). Rather than assuming that all isolated documents represent retrieval noise, we conducted a qualitative forensic audit on a random sample ($n = 30$, seed 42) from the Topic~$-1$ pool of the large-scale Electrophysiology corpus. The audit revealed that $20.0\%$ ($6/30$) of records were genuine retrieval noise introduced by automated keyword/API harvesting (e.g., off-target machine learning papers in cybersecurity, drone vision, and plant disease classification); $16.7\%$ ($5/30$) represented interdisciplinary or peripheral boundary applications (e.g., virtual-reality traffic safety and commercial wearable sleep tracking); and $63.3\%$ ($19/30$) were authentic, in-domain publications that fell below the density threshold ($m_{\text{cl}} = 10$) in high-dimensional embedding space. Isolating low-density boundary records rather than forcing them into artificial thematic clusters (as occurs under traditional $k$-means or Dirichlet models) preserves cluster topic purity and lexical diversity ($\overline{\text{TD}} = 0.80$), but incurs a recall penalty on sparsely populated subfields. Moreover, in small or low-density corpora (such as the 148-paper Blockchain benchmark), density clustering presents a known failure mode: with fixed $m_{\text{cl}} = 10$, all documents were relegated to Topic~$-1$ ($100.0\%$ outliers, $0$ discovered themes), demonstrating the necessity of adaptive parameter scaling or fallback heuristics for compact datasets. Regarding semantic coherence, empirical $C_{\text{NPMI}}$ values evaluated under standard Laplace-smoothed co-occurrence (Eq.~\ref{eq:npmi}) capture lexical co-occurrence relative to individual word frequencies. Because c-TF-IDF keyword extraction prioritizes cluster-discriminating technical terms rather than globally frequent collocations, the pointwise mutual information distribution reflects topic-specific vocabulary specialization across distinct semantic clusters \cite{hoyle2021automated, roder2015exploring}.

Third, the pipeline adapts to corpus scale dynamics. In compact corpora ($N < 500$), OpenSciencePipe extracts 2--4 primary clusters, avoiding over-segmentation. Conversely, in large-scale literature collections such as the 57,601-paper Electrophysiology benchmark, the architecture discovers 381 granular sub-themes while maintaining strong lexical separation ($\text{TD} = 0.6236$).

\subsection{Geopolitical Macro-Structural Concordance}
As reported in Table~\ref{tab:validation_thematic_clustering}, evaluation across geopolitical dimensions demonstrated strong topological fidelity against published ground truth. At the geopolitical level ($K=15$), OpenSciencePipe replicates $93.3\%$ of the Top-15 publishing nations on the $>50{,}000$-paper Electrophysiology corpus with near-perfect rank preservation ($\mathbf{\rho = 0.9912, p < 0.001}$, on $n=14$ conjoint nations). On the clinical ChatGPT benchmark, the pipeline achieves $100.0\%$ Top-15 nation overlap ($\mathbf{\rho = 0.9607, p < 0.001}$, on $n=15$ nations). On smaller corpora with published Top-5 rankings, where sample sizes for conjointly identified nations are constrained ($n = 3\text{--}4$), positive rank concordance was observed in Microplastics ($n=4, \rho = 0.80$), Environmental Science ($n=4, \rho = 0.80$), and Blockchain ($n=3, \rho = 1.00$). Conversely, on the leading universities benchmark, the pipeline observed an inverted rank correlation ($\rho = -1.00$ on $n=3$ conjoint nations), reflecting divergence between Scopus (which ranks nations by fractional author institutional affiliations) and OpenAlex (which weights author-level country attributions directly). Negative rank concordance was also observed for Mobile Commerce ($n=4, \rho = -0.40$). As noted, rank correlations on small conjoint depths ($n \le 5$) are purely descriptive and should not be interpreted as inferential evidence; overlap percentages and ordinal rankings quantify distinct structural properties.

While national-level geopolitical attributions map to standardized ISO entities across databases, institutional-level rank concordance was excluded from the primary quantitative benchmark suite. In proprietary commercial databases (Web of Science and Scopus), institutional rankings rely on proprietary entity-resolution algorithms that aggregate diverse departmental strings, multi-campus university systems, and affiliated teaching hospitals under unified corporate parent hierarchies. In contrast, open bibliographic platforms (such as OpenAlex and Crossref) structure affiliations through persistent Research Organization Registry (ROR) identifiers or raw institutional strings \cite{visser2021large, martin2021google}. Evaluating institutional ranking fidelity across distinct platforms therefore conflates algorithmic pipeline concordance with database-specific parent-child organizational taxonomies. Consequently, we restrict macro-structural validation to unambiguous, standardized national-level publication topologies.

\subsection{Computational Scalability: GPU vs. CPU Performance}
To assess computational scalability, community detection and centrality calculations were benchmarked on the 57,601-document Electrophysiology co-authorship network (comprising 118,338 author nodes and 569,295 collaborative edges). Benchmarks were executed under controlled conditions on an AMD Ryzen 7 3700X CPU (8 cores, 16 threads, 3.6--4.4\,GHz, 32\,GB host RAM) and an NVIDIA GeForce RTX 2060 GPU (6\,GB GDDR6 VRAM, Turing architecture). The single-threaded CPU baseline using NetworkX required 28.0 minutes (1,680.0 seconds) to complete Louvain community partitioning and PageRank computation, with host RAM utilization exceeding 12\,GB due to Python object overhead. In contrast, using NVIDIA RAPIDS \texttt{cugraph}, the identical workflow executed in \textbf{0.84 seconds} on GPU hardware, delivering a $2{,}000\times$ speedup over the CPU baseline while achieving equivalent community modularity ($Q = 0.9009$). Graph representations reside entirely within on-device Compressed Sparse Row (CSR) memory, removing the computational bottleneck that historically constrained science mapping to small or moderately sized literature samples.

\subsection{Head-to-Head Algorithmic Baselines: Neural Thematic Modeling vs. Classical LDA}
\label{sec:head_to_head_baselines}
To establish empirical baselines against classical scientometric paradigms, Table~\ref{tab:baseline_thematic_graph} reports head-to-head evaluations of thematic modeling and graph community partitioning across five benchmark corpora spanning compact, domain-specific, and large-scale literature collections.

\input{tables/tab_baseline_thematic_graph.tex}

Across both compact and large-scale corpora, classical Latent Dirichlet Allocation \cite{blei2003latent} exhibits a fundamental structural trade-off compared to density-based neural modeling. Because LDA relies on a Dirichlet-multinomial mixture model that assumes every document is generated by a distribution over topics, it forces every publication into its highest-probability topic component, resulting in an invariant $0.0\%$ outlier rate. However, forcing peripheral or interdisciplinary publications into primary domain clusters dilutes vocabulary distinctiveness: in BCI Stroke Rehabilitation ($N = 191$), LDA topic diversity drops to $\text{TD} = 0.4000$ at $K=10$ (reflecting extensive vocabulary sharing across topics), whereas BERTopic achieves $\text{TD} = 1.0000$ by isolating $25.4\%$ of boundary literature into Topic~$-1$. On the 57,601-paper Electrophysiology corpus, LDA produces broad, overlapping themes ($\text{TD} = 0.7100\text{--}0.7400$) at substantial computational cost (88.4--94.8\,s), whereas BERTopic discovers 553 granular sub-themes while preserving distinct vocabulary centroids ($\text{TD} = 0.6863$) through explicit HDBSCAN density isolation ($38.9\%$ outliers).

In co-authorship graph analytics, GPU acceleration via \texttt{cugraph} provides sub-second execution across all evaluated corpora (from 3.1\,ms on compact networks to 0.84\,s on 569,295 edges), maintaining high community modularity ($Q \ge 0.90$) across all scales. While NetworkX provides rapid execution on small networks ($< 1{,}000$ edges), latency scales super-linearly on dense collaborative networks, exceeding 28 minutes on large corpora where GPU execution finishes in under one second.

\section{Discussion}
\label{sec:discussion}
\subsection{Bridging Science Mapping and Evidence Synthesis}
Although science mapping and systematic reviews analyze the same underlying scholarly literature, they have historically required completely separate software ecosystems: exploratory tools for topological mapping (e.g., VOSviewer, Bibliometrix) and dedicated statistical platforms for evidence synthesis (e.g., RevMan, metafor). This separation forces researchers into redundant data harvesting, inconsistent preprocessing, and manual file handling. OpenSciencePipe provides a unified computational pipeline where a single canonical corpus branches directly into either macro-level network extraction or micro-level eligibility screening and statistical pooling.

\subsection{Comparative Functional Audit: Workflow Migration and Usability Trade-offs}
The quantitative concordance evidence is reported in Section~\ref{sec:results}; this subsection instead audits what a researcher gives up and gains when migrating from legacy tools, focusing on onboarding cost, cognitive friction, and workflow control.

\paragraph{Onboarding and Interface Overhead}
VOSviewer, CiteSpace, and SciMAT expose their analytical choices through multi-dialog graphical interfaces. A first-time user must learn the vocabulary of each tool, such as thesaurus files, counting methods, normalization options, time-slicing windows, and node-selection thresholds, and must set these across successive panels, often with defaults that are not recorded alongside the exported figure. CiteSpace in particular couples manual one-year slicing with pruning and pathfinding options whose interaction is difficult to document. The learning curve is therefore front-loaded, and reproducing an analysis months later depends on the analyst's memory or screenshots. OpenSciencePipe replaces this interaction sequence with a single declarative specification (a query, a year range, and a record limit) from which every downstream parameter is derived or logged, so the cognitive cost shifts from navigating dialogs to formulating a well-posed search.

\paragraph{Data Provenance and Hand-off Friction}
Legacy mappers assume that the user has already assembled a flat file from a commercial index, which makes the corpus an undocumented intermediate artifact. Bibliometrix reduces some of this friction through scripting but remains tied to its import formats and an interactive Shiny session. Because OpenSciencePipe harvests, deduplicates, analyses, and typesets within one run, the corpus, intermediate tables, and manuscript fragments share a single provenance trail, and rerunning the specification regenerates all of them.

\paragraph{Topic Modeling and Screening Workflows}
Moving from classical LDA to embedding-based clustering changes how analysts interpret results: instead of inspecting forced topic lists, they review an explicit noise pool and decide whether peripheral literature merits separate attention. For screening, Rayyan and ASReview keep a human in every labeling decision, which preserves reviewer judgment but sustains the labor burden. OpenSciencePipe instead screens autonomously via local open-weight LLMs with structured JSON schema constraints ($T=0.0$), trading some interpretive control for a large reduction in routine labeling; the deterministic audit trace lets reviewers inspect decisions afterwards. Likewise, replacing RevMan or \texttt{metafor} data entry with automated parameter extraction removes transcription errors but moves verification to the extraction stage.

\paragraph{Trade-offs and Residual Advantages of Legacy Tools}
Migration is not uniformly beneficial. Interactive tools offer immediate visual exploration, manual relabeling of clusters, and decades of community documentation that a command-line pipeline cannot match. A declarative workflow also demands comfort with a terminal and, for GPU acceleration, a compatible NVIDIA device. We therefore position OpenSciencePipe as a complement for reproducible, large-scale, or repeated analyses, while small one-off explorations may remain better served by a GUI.

\paragraph{Where OpenSciencePipe Introduces Genuinely New Capabilities}
To our knowledge, no legacy tool spans the continuum from programmatic multi-source harvesting to camera-ready manuscript compilation. A single declarative terminal command or API query executes the complete workflow: multi-source open harvesting $\to$ token-sorted Levenshtein deduplication $\to$ GPU Louvain community partitioning $\to$ neural topic modeling with Topic~$-1$ noise rejection $\to$ camera-ready \LaTeX{} manuscript compilation with synchronized vector plots and tables.

\subsection{Implications for Open Science and Informetrics}
The high concordance observed between OpenSciencePipe and published benchmarks originally executed on Web of Science or Scopus confirms the maturity of open scholarly metadata. By building on public endpoints such as OpenAlex and Crossref, the framework removes the dependency on expensive proprietary database subscriptions.
As demonstrated on corpora exceeding 50,000 publications, OpenSciencePipe executes without relying on commercial cloud language model APIs. Combined with GPU network processing optimized for older consumer graphics cards with 6~GB of memory, the entire workflow operates locally at zero marginal cost. This minimal barrier to entry enables independent scholars and institutions with limited research budgets to perform large-scale, fully reproducible science mapping and systematic reviews.

\subsection{Informetric Validity and Database Coverage Boundaries}
A fundamental methodological consideration in informetric replication is the operational boundary between algorithmic concordance and database coverage divergence. Comparative investigations by Visser et al. \cite{visser2021large} and Mart{\'i}n-Mart{\'i}n et al. \cite{martin2021google} established that while proprietary commercial databases (Web of Science and Scopus) maintain selective core indexing, open bibliographic platforms (OpenAlex, Crossref) provide broader coverage of open-access literature, conference proceedings, and non-Anglophone scholarship. Consequently, observing strong ordinal alignment ($\rho > 0.80$) against published WoS- and Scopus-derived baselines confirms that OpenSciencePipe recovers consistent macro-level geopolitical topologies across distinct data infrastructures, demonstrating that open metadata can support reproducible informetric science mapping without commercial database lock-in.

Furthermore, a persistent challenge in automated informetric workflows is author homonymy and entity splitting. While OpenSciencePipe disambiguates authors via the multi-signal protocol detailed in Section~\ref{sec:tier3}, residual name variants and homonymous merges remain visible in dense collaborative network topologies, particularly when common surnames lack persistent ORCID linkages or institutional metadata. Benchmarking automated disambiguation accuracy against verified gold-standard author registries (such as ORCID-curated sub-graphs) remains an important focus for ongoing development.

\subsection{Limitations and Future Work}
While OpenSciencePipe automates the pipeline from API query to \LaTeX{} manuscript synthesis, human oversight remains essential for qualitative contextualization and domain-specific interpretation. Several engineering and methodological avenues will be pursued in future work. 

First, regarding dual interface ecosystems and GUI enhancements, ongoing work focuses on embedding interactive graph curation controls directly into the web visualizer studio, bridging headless cluster execution with exploratory visual filtering. Second, for multi-modal full-text PDF extraction, current bibliometric parsing extracts metadata from rich abstracts and open-access metadata harvested via Unpaywall and PMC; incorporating vision-language parsing will allow the autonomous extraction of high-resolution figures, tabular data, and citation context directly from complex multi-column PDFs. Third, the development of living bibliometric citation monitors utilizing persistent webhook triggers and scheduled API polling will enable dynamic monitoring that autonomously alerts researchers to newly indexed landmark publications, updating living science maps and collaborative networks in real time.

\section{Conclusion}
\label{sec:conclusion}
In this paper, we introduced \textbf{OpenSciencePipe}, an integrated, open-source computational framework for autonomous bibliometric discovery and science mapping. OpenSciencePipe integrates multi-source API harvesting (OpenAlex, Crossref, Semantic Scholar, PubMed), programmatic Levenshtein deduplication, GPU-accelerated graph analysis via RAPIDS \texttt{cugraph}, contextual neural topic modeling via BERTopic with density-based noise rejection (Topic~$-1$), and automated publication-grade \LaTeX{} compilation.

Across an empirical validation suite of published benchmark corpora, the framework demonstrated high topic diversity with explicit noise isolation, strong rank concordance with published geopolitical hierarchies on large corpora ($\rho \ge 0.96, p < 0.001$), and sub-second GPU community partitioning on co-authorship networks of over 118,000 nodes, delivering a $2{,}000\times$ speedup over CPU baselines. Head-to-head baseline comparisons against classical Latent Dirichlet Allocation confirm that density-based outlier isolation prevents semantic cluster dilution. By providing an open, high-performance, and reproducible foundation, OpenSciencePipe removes commercial database lock-in and manual workflow bottlenecks in computational informetrics.
